# Brooke Smilen

A minimal, static portfolio for GitHub Pages. No build tools or package installation required.

## Preview

Run `python3 -m http.server 8000` from this folder.

## Publish

Upload these files to a repository named `bsmilen575.github.io`. In Settings → Pages, select Deploy from a branch → main → / (root).

The site will be served at https://bsmilen575.github.io/. Keep custom-domain configuration unset until the domain migration is ready.

## Editing

- About text: `index.html`
- Shared appearance: `styles.css`
- Project pages: `work/`
- Fiction and poems: `writing/`
- Current research: `research/`

Existing prose and writing were migrated from brookesmilen.com. Interactive demos that require the old host's application/backend have not been migrated. The homepage biography was supplied by Brooke and links to Shannon (1951).
